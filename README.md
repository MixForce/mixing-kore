<h1 style="text-align: center; color: #666;"><i>MixingKore</i></h1>

<p style="text-align: center; color: #777;"><i>Performance algorithm library for Minecraft mods.</i></p>

---

<div style="margin-left: 2.5em; color: #7F7F7F;">

<h2 style="margin-top: 0.4em;">Components</h2>

- <code style="font-style: italic;">AccurateMath</code>, <code style="font-style: italic;">FastMath</code>, <code style="font-style: italic;">RoughMath</code> · Approx. math
- <code style="font-style: italic;">BitVec</code> · Bit packing and bitwise operations.
- <code style="font-style: italic;">Arcanum</code> · Stronghold ray dynalocation.
- <code style="font-style: italic;">Canere</code> · Hybrid heuristic anvil solver.
- <code style="font-style: italic;">FastLoc</code> · Performance <code>Vec3</code> / <code>BlockPos</code> alternatives.

<h2 style="margin-top: 0.4em;">Installation</h2>

```groovy
dependencies {
    implementation "io.github.mixforce:mixing-kore:1.0.0"
}
```

<h2 style="margin-top: 0.4em;">Constraints</h2>

- <code style="font-style: italic;">AccurateMath</code>, <code style="font-style: italic;">FastMath</code>, <code style="font-style: italic;">RoughMath</code> · approximate.
- <code style="font-style: italic;">Canere</code> · experimental.
